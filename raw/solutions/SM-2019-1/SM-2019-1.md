## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

本題為名詞解釋題，各名詞詳細意涵說明如下：

**(一) 含水量（moisture content, water content, $w$）**
1. **定義：** 土壤中水分重量 ($W_w$) 與固體顆粒重量 ($W_s$) 的比值，通常以百分比表示。
2. **公式：** $w = \frac{W_w}{W_s} \times 100\%$
3. **工程意義：** 含水量是土壤最基本的物理性質之一，直接影響細粒土壤的狀態（稠度）、剪力強度與壓縮性。對於夯實工程，需控制含水量在最佳含水量 ($w_{opt}$) 附近，以達到最大乾密度。

**(二) 過壓密比（overconsolidation ratio, OCR）**
1. **定義：** 土壤在歷史上曾經受過的最大有效應力（預壓密應力，$\sigma_c'$ 或 $p_c'$）與目前所受現地有效應力（$\sigma_o'$ 或 $p_o'$）之比值。
2. **公式：** $OCR = \frac{\sigma_c'}{\sigma_o'}$
3. **工程意義：** 
   - $OCR = 1$：正常壓密土壤 (NC)，代表土壤目前承受的應力即為歷史最大。壓縮性較高，剪力強度較低。
   - $OCR > 1$：過壓密土壤 (OC)，代表土壤曾受過比現在更大的應力。壓縮性較低（變形量小），剪力強度較高，且受剪時可能會有體積膨脹現象（剪脹性，Dilatancy）。
   - $OCR < 1$：欠壓密土壤，通常指尚未完成壓密之新填土。

**(三) 摩爾-庫倫破壞準則（Mohr-Coulomb failure criterion）**
1. **定義：** 描述土壤受剪破壞的強度包絡線理論。該準則認為土壤的破壞是由剪應力與法向應力的組合所造成，且剪力強度為破壞面上法向應力的線性函數。
2. **公式：** 
   - 總應力法：$\tau_f = c + \sigma \tan \phi$（短期、不排水）
   - 有效應力法：$\tau_f = c' + \sigma' \tan \phi'$（長期、排水）
3. **工程意義：** 其中 $c$ 或 $c'$ 為凝聚力（截距），$\phi$ 或 $\phi'$ 為內摩擦角（斜率）。此準則在莫爾圖（Mohr circle）中形成一條直線包絡線，當土壤內任一點的莫爾圓與此包絡線相切時，該點即發生剪力破壞。破壞面與大主應力面之夾角為 $45^\circ + \phi/2$。此為土壤力學中最廣泛使用之強度破壞準則。

**(四) 紅土化（laterization）**
1. **定義：** 在熱帶或亞熱帶高溫多雨的氣候環境下，岩石或土壤經歷強烈的化學風化作用與淋洗作用（Leaching）的過程。
2. **特徵：** 過程中可溶性的鹼金屬、鹼土金屬及二氧化矽（矽酸鹽）被大量淋洗流失，而較不易溶解的鐵、鋁氧化物則大量殘留富集於表層，使土壤呈現紅褐色或黃褐色，稱為紅土（Laterite）。
3. **工程意義：** 紅土化所生成的紅土通常具有較好的水穩性與結構性，在未擾動狀態下具有較高的剪力強度及較低的壓縮性，為良好的地基與路基材料。但若遭過度擾動或含水劇烈變化，部分紅土可能會因內部所含之特殊黏土礦物而展現膨脹性或強度大幅折減。

**(五) 群樁效率（group efficiency, $E_g$）**
1. **定義：** 群樁之極限承載力與單獨一根樁之極限承載力乘上樁數之比值。
2. **公式：** $E_g = \frac{Q_{g(group)}}{n \cdot Q_{u(single)}}$
   - $Q_{g(group)}$：群樁系統總極限承載力
   - $n$：群樁之樁數
   - $Q_{u(single)}$：單樁之極限承載力
3. **工程意義：** 由於群樁在土壤中產生應力重疊效應，特別在黏土中，群樁總承載力通常小於單樁承載力之總和（即 $E_g < 1$），甚至可能發生塊體破壞（Block failure）。但在密集打擊於緊密砂土時，因夯實擠壓效應，效率可能大於 1（但規範通常保守取 $E_g = 1$）。設計時須考慮群樁效率以安全地評估總承載力。

**(六) 液性指數（liquidity index, $LI$ 或 $I_L$）**
1. **定義：** 描述細粒土壤目前天然含水量 ($w_n$) 相對於其塑限 ($PL$) 與液限 ($LL$) 之相對位置的指標。
2. **公式：** $LI = \frac{w_n - PL}{LL - PL} = \frac{w_n - PL}{PI}$ （其中 $PI$ 為塑性指數）
3. **工程意義：** 藉由 $LI$ 可判斷原狀黏土之物理狀態：
   - $LI < 0$（即 $w_n < PL$）：處於固態或半固態，具有高強度、低壓縮性，受力容易發生脆性破壞。
   - $0 \le LI \le 1$（即 $PL \le w_n \le LL$）：處於塑性狀態，可發生塑性變形。
   - $LI > 1$（即 $w_n > LL$）：處於液態或黏滯流體狀態。當天然含水量超過液限，此時土壤若受擾動，其強度將急遽下降，可能為靈敏黏土（Sensitive clay）或具流動性之軟弱黏土。

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)
- **紅土化**的工程性質常因地區而異。在名詞解釋中，點出其化學風化的本質（鐵鋁富集、矽流失）與呈現顏色為給分關鍵，若能補充其力學性質（未擾動強度佳）會更加完整。
- **摩爾-庫倫破壞準則**，務必寫出總應力與有效應力兩種表達式，才能完整呈現工程應用的兩大面向（短期穩定與長期穩定分析）。
- **液性指數 (LI)** 與**塑性指數 (PI)** 的差異常被混淆。PI 表示土壤呈塑性的含水量區間範圍 ($LL - PL$)，代表土壤的塑性高低；而 LI 則是一個無因次指標，表示目前天然含水量在該區間中的相對位置。答題時寫出公式即可清楚區分兩者。
