# 總應力法 vs 有效應力法

**分類：** Layer 2 設計哲學
**相關單元：** [[SM-U1-4]] 土體內應力、[[SM-U1-5]] 土壤強度特性與變形性、[[SM-U2-1]] 淺基礎之支承力與沉陷量、[[SM-U3-3]] 坡地工程

---

## 核心議題

土壤力學分析的第一個岔路口，永遠是「這個問題該用總應力（φ=0、Su）分析，還是用有效應力（c'、φ'）分析？」選錯分析法，後面公式再精熟也是白算。核心原因在於：土壤的強度與變形行為，物理上是由**有效應力** $\sigma' = \sigma - u$ 控制的（見 [[EFFECTIVE-STRESS-PRINCIPLE]]），但工程上為了避開「精確預測施工期孔隙水壓」這個極困難的問題，發展出用總應力參數（$S_u$、$\phi=0$）直接包裹住孔隙水壓效應的簡化分析法。

## 判斷準則 / 決策依據

| 情境 | 建議分析法 | 原因 |
|------|-----------|------|
| 飽和黏土、施工期短（快速加載/開挖） | 總應力法（$\phi=0$、$S_u$） | 孔隙水壓來不及消散，用不排水強度直接包裹該效應最安全、最貼近現場行為 |
| 飽和黏土、長期使用階段 | 有效應力法（$c'$、$\phi'$） | 孔隙水壓已消散至穩態，須用有效應力參數評估長期穩定性 |
| 砂土（透水性高） | 有效應力法 | 砂土排水快，任何階段孔隙水壓都能視為已消散，總應力分析對砂土無意義 |
| 開挖基盤隆起（[[EXCAVATION-STABILITY]]） | 總應力法 | 屬短期施工穩定性問題，用 $S_u$ 搭配 $N_c$ 檢核最保守也最常見 |
| 邊坡長期穩定（[[SLOPE-STABILITY-ANALYSIS]]） | 有效應力法 | 邊坡多數破壞發生在長期滲流狀態下，需用 $c', \phi'$ 搭配孔隙水壓 |
| 邊坡剛開挖/加載後之短期穩定 | 總應力法 | 短期內孔隙水壓來不及消散，用不排水強度分析最保守 |

## 對應公式或方法

- 總應力法核心：$\tau_f = S_u$（即 $c=S_u, \phi=0$），來自 [[TRIAXIAL-TEST-TYPES]] 之 UU 試驗。
- 有效應力法核心：$\tau_f = c' + \sigma' \tan\phi'$（見 [[MOHR-COULOMB-FAILURE-CRITERION]]），參數多來自 CU（含孔隙水壓量測）或 CD 試驗。
- 兩者在同一題目中經常「先總應力法驗算施工期，再有效應力法驗算長期」雙軌並用，這正是 `designMethod: 混合` 題目的典型出題手法。

## 常見誤用陷阱

- 對飽和黏土的長期沉陷/穩定問題，誤用 $\phi=0$ 總應力法，會嚴重低估長期強度變化（正常壓密黏土長期強度通常高於短期不排水強度）。
- 對施工期短期問題，誤用有效應力法卻沒有能力預測施工期孔隙水壓變化，導致分析看似「精確」實則失真。
- 忽略地下水位變動對總應力法完全無感（$S_u$ 為試驗量測值，不隨水位變動即時改變），但有效應力法必須即時反映水位。
