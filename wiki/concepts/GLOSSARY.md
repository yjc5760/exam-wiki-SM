## 第一單元：土壤基本性質、滲透、夯實壓密、應力、強度

| 概念 | 一句話定義 |
|------|-----------|
| 土壤三相關係 | 以土粒-水-空氣三相圖換算孔隙比、含水量、飽和度、單位重 |
| 阿太堡限度 | 液性/塑性限度界定細粒土的稠度狀態轉換點 |
| 統一土壤分類系統（USCS） | 依級配與塑性圖將土壤分為粗粒土（G/S）與細粒土（M/C） |
| 達西定律 | 滲流速度與水力坡降成正比（v = ki） |
| 流網分析 | 以流線與等勢線求算滲流量與孔隙水壓分布 |
| 夯實曲線 | 乾密度與含水量的鐘形關係，峰值為最佳夯實條件 |
| Terzaghi 一維壓密理論 | 描述飽和黏土隨孔隙水排出而產生長期沉陷的過程 |
| 過壓密應力與 OCR | 土層歷史最大有效應力，決定沉陷計算應用 Cc 或 Cr |
| 壓密係數與時間因數 | 決定壓密速率與達到特定壓密度所需時間 |
| 有效應力原理 | σ' = σ - u，控制土壤強度與變形的是有效應力 |
| Boussinesq 應力增量理論 | 求算外加載重在土體內任一深度造成的應力增量 |
| Mohr-Coulomb 破壞準則 | τf = c' + σ'tanφ'，土壤剪力強度的基本準則 |
| 不排水剪力強度 | 飽和黏土 φ=0 條件下的強度指標 Su |
| 三軸試驗分類 | UU/CU/CD 對應不同排水條件與分析情境 |

## 第二單元：淺基礎、深基礎、開挖、基礎型式、地層改良

| 概念 | 一句話定義 |
|------|-----------|
| 淺基礎承載力理論 | Terzaghi/Meyerhof 公式疊加凝聚力、覆土、土重三項求極限承載力 |
| 瞬時沉陷與壓密沉陷 | 基礎總沉陷由彈性沉陷、壓密沉陷、次壓縮沉陷組成 |
| 樁基承載力組成 | Qu = Qp（端點）+ Qs（摩擦力） |
| 群樁效應 | 群樁承載力與沉陷不同於單樁簡單疊加 |
| 開挖穩定性 | 需同時檢核擋土結構強度、基盤隆起、砂湧管湧風險 |
| 地層改良方法 | 夯實、排水固結、灌漿、置換、化學攪拌等改善地層方法 |

## 第三單元：側向土壓力、擋土結構、坡地工程、生態工法

| 概念 | 一句話定義 |
|------|-----------|
| Rankine 土壓力理論 | 假設牆背垂直光滑、填土水平的主動/被動土壓力計算法 |
| Coulomb 土壓力理論 | 可考慮牆背傾角、填土坡度、牆土摩擦角的土壓力計算法 |
| 擋土結構穩定分析 | 抗滑動、抗傾覆、承載力、整體穩定四項獨立檢核 |
| 邊坡穩定分析 | 以 Fellenius 法或 Bishop 法沿滑動面求安全係數，搜尋臨界滑動面 |
