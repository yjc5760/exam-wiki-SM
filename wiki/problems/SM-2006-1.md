# SM-2006-1 — Mohr-Coulomb破壞準則、極限平衡、十字片剪試驗

**來源：** 結構工程技師高考 · 土壤力學與基礎設計 · 第1題

**主分類：** [[SM-U1-5]] 土壤強度特性與變形性
**副分類：** [[SM-U1-3]] 土壤夯實及壓密
**分析法：** 概念題

## 題幹摘要

一、簡答題：
(一) 試說明 c－φ 土壤元素達極限平衡之應力狀態（stress state of c－φ soil under limit equilibrium）。（10 分）
(二) 試說明十字片剪試驗方法（Vane shear test）與土壤強度決定方法。（10 分）
(三) 試說明土壤過壓密比（over-consolidation ratio）。（5 分）

## 核心考點

本題為基礎的土壤力學概念題，涵蓋了土壤剪力強度的基本準則、現場量測方法，以及應力歷史的關鍵指標。
出題者意在測試考生對於：
1. **Mohr-Coulomb 破壞準則的理解**：能否精確描述 c-φ 土壤在極限平衡狀態下的主應力關係（$\sigma_1$ 與 $\sigma_3$ 的關係）及破壞面上的剪應力與正向應力關係。
2. **現地強度試驗（Vane Shear Test）的熟悉度**：能否說明該試驗的適用土層（軟弱飽和黏土）、試驗原理（圓柱體扭轉剪力破壞），以及如何由扭矩反推不排水剪力強度（$S_u$）。
3. **過壓密比（OCR）的定義與物理意義**：是否清楚最大過去有效應力（$p_c'$ 或 $\sigma_{vm}'$）與現有有效覆土應力（$p_0'$ 或 $\sigma_{v0}'$）的關係，並理解其對土壤變形與強度特性的影響。

## 解題關鍵步驟

**戰略地圖**：
- (一) 以 Mohr 圓與 Coulomb 破壞包絡線相切之幾何關係出發，推導並寫出破壞面上的應力狀態方程式 $\tau_f = c + \sigma \tan\phi$，以及大、小主應力之間的關係式 $\sigma_1 = \sigma_3 \tan^2(45^\circ + \phi/2) + 2c \tan(45^\circ + \phi/2)$。並說明破壞面與大主應力作用面之夾角為 $\theta = 45^\circ + \phi/2$。
- (二) 十字片剪試驗：說明適用條件（軟弱飽和黏土），試驗步驟（插入、等速旋轉測最大扭矩），並列出破壞力矩 $T$ 與不排水剪力強度 $S_u$ 的平衡方程式。注意區分頂底面也有抗剪貢獻。
- (三) 過壓密比：寫出定義方程式 $OCR = p_c' / p_0'$，並輔以說明 $OCR=1$（正常壓密）及 $OCR>1$（過壓密）的物理意義。

## 用到的公式

$$\tau_f = c + \sigma_f \tan\phi$$

$$\sigma_1 = \sigma_3 \tan^2\left(45^\circ + \frac{\phi}{2}\right) + 2c \tan\left(45^\circ + \frac{\phi}{2}\right)$$

$$T = S_u \cdot \left[ \pi D \cdot H \cdot \frac{D}{2} + 2 \cdot \frac{\pi D^2}{4} \cdot \left(\frac{D}{3}\right) \right]$$

$$S_u = \frac{T}{\pi D^2 \left( \frac{H}{2} + \frac{D}{6} \right)}$$

$$OCR = \frac{p_c'}{p_0'}$$

## 涉及陷阱

**陷阱分析**：
- 在(一)中，僅寫出 $\tau_f = c + \sigma \tan\phi$ 可能不夠完整，應補充主應力關係及破壞面包角。
- 在(二)中，推導 $S_u$ 時，需注意十字片剪的抗扭矩來源包含「圓柱側面積」與「圓柱上、下底面積」。若只寫出公式而未解釋由來，分數可能打折。
- 在(三)中，務必強調是「有效應力」（預壓密有效應力 vs 現有有效應力），若寫成總應力則為嚴重觀念錯誤。
