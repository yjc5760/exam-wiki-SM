# 失敗模式分類（Layer 5）

> 依 SM 科目常見破壞機制分類，幫助考生建立「這題若做錯會導致哪種破壞」的直覺。
> 由 Cowork 直接維護。

---

## 五大類別

| 類別 | 頁面 | 說明 |
|------|------|------|
| 承載力破壞 | [bearing-capacity-failure.md](bearing-capacity-failure.md) | 淺基礎/樁基超過極限承載力，發生整體剪力破壞或沖剪破壞 |
| 過大沉陷 | [excessive-settlement.md](excessive-settlement.md) | 瞬時沉陷、壓密沉陷或差異沉陷超過容許值，未必伴隨強度破壞 |
| 滲流破壞 | [seepage-failure.md](seepage-failure.md) | 砂湧（boiling）、管湧（piping）、基盤隆起，因滲流力或水壓過大導致 |
| 邊坡滑動 | [slope-failure.md](slope-failure.md) | 邊坡沿滑動面失穩，安全係數 FS < 1 |
| 擋土結構失穩 | [retaining-structure-failure.md](retaining-structure-failure.md) | 擋土牆滑動、傾覆、承載力不足或整體滑動失穩 |

> 五大類別已建立初版內容，後續可依實際解題累積持續補充案例與細節。
